EN.601.612 — Big Data Systems

Teaching Assistant, Fall 2026. Johns Hopkins University, 3 credits.

An introduction to big data processing, its underlying technologies, managing the inter-relation of components in a system at scale, and the construction of analytical pipelines that provide business value. Key technologies include NoSQL databases, Hadoop ecosystems, distributed processing frameworks such as Apache Spark, data warehousing solutions such as Hive, and streaming platforms such as Kafka. Emphasis is placed on the architectural design and operational challenges of big data ecosystems.

Required background: data structures and computer system fundamentals, or permission. Prior knowledge of databases or parallel computing recommended.

EN.601.620 — Parallel Programming & Performance Engineering

Teaching Assistant, Fall 2022. Course Assistant, Fall 2023 and Fall 2024. Johns Hopkins University, 3 credits.

The course guides the learner to write efficient software, with a focus on exploiting hardware parallelism and efficient memory usage. Modern microprocessors implement parallelism at many levels — instruction level, vectorization, pipelining, multicore and memory — and naive implementations realize only a fraction of the available performance. Exploiting these capabilities requires understanding algorithms, computer architecture and systems (compilers, PL, OS), and how they interact. Programming is mostly in C/C++, where most performance-oriented software is written, and the course also covers parallel programming in Python and CUDA for GPUs.

Required background: familiarity with Python.
